# SPOTeval-proton-spot-analysis

SPOTeval is a MATLAB-based software tool for analysis of proton pencil-beam spot measurements acquired with radiochromic film or scintillator-camera systems. The software supports ROI selection, orthogonal profile extraction, Gaussian fitting, FWHM/sigma/penumbra/symmetry calculations, two-dimensional spot-shape and rotational-symmetry analysis, batch reporting, and TPS-compatible W2CAD export.
